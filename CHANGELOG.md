# Changelog

## 1.1.0 — 2026-08-05

- Added English, Traditional Chinese, and Japanese desktop UI switching with English as the default.
- Added rotating desktop logs, an in-window log viewer, CLI debug options, and Android logcat/in-app log export.
- Added TGA, DDS, PCX, PPM, PGM, PBM, reStructuredText, LOG, NFO, JSON Lines, TOML, TSV, TAR.BZ2, TAR.XZ, Opus, WMA, AIFF, M4V, FLV, MPEG, 3GP, OGV, and MPEG-TS registration and conversion handling.
- Added a native Kotlin Android application for image, text, JSON, JSON Lines, CSV, and TSV conversion through the system document picker.
- Added Android unit tests, APK build validation, and an emulator startup/UI/logcat workflow.
- Added Android APK packaging to tagged releases.

## 1.0.0 — 2026-08-04

- Added the Traditional Chinese desktop conversion window.
- Added compatible-target filtering and conversion risk assessment.
- Added image, text, structured-data, archive, audio, and video conversion groups.
- Added atomic destination writes, explicit overwrite control, and recycle-bin source replacement.
- Added protected ZIP/TAR repacking and FFmpeg process isolation.
- Added CLI operation, test coverage, PyInstaller packaging, CI, and tagged GitHub Releases.
